# Proof: dim H⁰ = dim Fix(Hol) ≤ d on ANY Connected Graph — Cycles Never Add Dimension

**Proved by:** Kimi k2d8 (OpenClaw fleet), verified numerically by `tests/test_dim_h0_fixed_space.py`
**Date:** 2026-10-03
**Status:** RIGOROUSLY PROVEN ✅ — and it *corrects* Corollary 3 of `PROOF-DIM-H0-EQUALS-9.md` and the "≤ 9 + 9·β₁" line in `README.md` / `PAPER.md`. See `ERRATA.md` entry 2026-10-03.

## Statement

Let Γ be a **finite connected graph** (cycles allowed), V a rank-d real vector
bundle on Γ: each vertex v carries V_v ≅ ℝ^d, each edge e: u→v an isomorphism
T_e: V_u → V_v with T_{e⁻¹} = T_e⁻¹. Fix a root r.

Let Hol_r ⊆ GL(V_r) be the **holonomy group** at r: all composites of edge
transports around closed walks based at r. Let

  Fix(Hol_r) = { v ∈ V_r : H v = v for all H ∈ Hol_r }.

Then restriction-to-root ρ: H⁰(Γ, V) → V_r is an isomorphism onto Fix(Hol_r),
and therefore

  **dim H⁰(Γ, V) = dim Fix(Hol_r) ≤ d.**

Equality dim = d holds iff the holonomy group is trivial (every cycle
transports identically). Cycles can only *remove* dimensions, never add them.

## Proof

*Step 1 — restriction is injective.* Pick a spanning tree T of Γ. Propagate
any root value along T (the tree proof in `PROOF-DIM-H0-EQUALS-9.md` applies
verbatim to T): a global section is determined by its value at r. So ρ is
injective and dim H⁰ ≤ dim V_r = d. ∎ (This already kills "≤ 9 + 9·β₁" as a
non-tight, mechanism-wrong bound: no β₁ term can appear.)

*Step 2 — image ⊆ Fix.* If s is a global section with s_r = v, consistency
around any closed walk γ based at r gives Hol(γ) v = v. Hence
ρ(H⁰) ⊆ Fix(Hol_r). ∎

*Step 3 — Fix ⊆ image.* Let v ∈ Fix(Hol_r). Extend v to all vertices by
propagation along T. For any edge e = (u, w) *not* in T, the unique T-path
r ↝ u, then e, then the T-path w ↝ r is a closed walk; its holonomy fixes v.
Unwinding: the value propagated to w equals T_e applied to the value at u —
the compatibility condition holds on every cotree edge too, so the extension
is a global section with root value v. Hence v ∈ ρ(H⁰). ∎

*Step 4 — closed form.* Steps 1–3 give ρ: H⁰ ≅ Fix(Hol_r). Now Hol_r is
generated by the holonomies of a cycle basis (cotree loops): the fundamental
group π₁(Γ, r) is free on β₁ generators, and Hol is a homomorphism from it.
"Fixed by the group" = "fixed by its generators", so

  dim H⁰ = dim ( ⋂_{i=1..β₁} Fix(Hol(γ_i)) ).

∎

## Consequences

1. **Tree case recovered:** Hol = {id}, Fix = whole fiber, dim = d = 9 —
   the existing tree theorem is the Hol-trivial special case.
2. **Generic cycles kill everything:** a single uniformly-random
   holonomy in GL(d) has no fixed vectors generically (characteristic
   polynomial det(Hol − I) ≠ 0 a.s.), so a generic one-cycle graph has
   dim H⁰ = 0: the spanning-tree propagation survives, but the cotree
   constraint eats all d dimensions.
3. **The "cycle adds 9 DOF" intuition is exactly backwards for linear
   stalks.** Where it *does* live: the **interval/tolerance sheaf** of
   Problem 1 (Intent–Holonomy Duality), where the answer set is a convex
   polytope and the right quantity is fiber *width/slack*, not dimension.
   There, holonomy can map an interval box into itself while shrinking it
   — slack lives in the inclusion, not in a dimension count. That is the
   open problem; the linear statement is now closed.
4. **Formula is computable:** dim H⁰ = nullity of the stacked system
   (s_w − T_e s_u = 0 over all edges) — numerically pinned in
   `tests/test_dim_h0_fixed_space.py` against the fixed-space formula on
   random graphs (d=3 bulk, d=9 spot checks).

## Relation to Problem 1 (Intent–Holonomy Duality)

The roadmap's (A) ⟺ (B) conjecture replaces "fixed points" with "interval
preservation": Hol(γ)(I) ⊆ I. For **linear** stalks the theorem above shows
the fixed-point version is the exact criterion and it is *checkable per
cycle-basis*. The interval version is genuinely harder (composition of
interval-preserving maps need not preserve intervals), which is precisely the
documented obstacle. This proof closes the linear case and names where the
difficulty actually starts.
